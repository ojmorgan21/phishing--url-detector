# 🛡️ PhishGuard - Phishing URL Detector

Is this link safe or a trap? Paste any suspicious link before you click it.

**Live Demo:** https://phishing-url-detector-xu2a.onrender.com

## What it does
- Checks for fake logins, typosquatting, IP tricks & more
- Gives instant SAFE / DANGER verdict + Risk Score / 10
- No signup, no download, private - we don't store URLs

## Try it
- Safe: `https://google.com`
- Phishing: `http://paypal-secure-login-verify.com`
- Phishing: `http://192.168.1.1/login`

## Tech
Python + Flask + Custom scoring engine
